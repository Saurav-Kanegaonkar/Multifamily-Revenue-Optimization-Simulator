# Analysis Plan

## Objective

Build a weekly revenue optimization artifact that helps a revenue analyst prepare for pricing reviews with regional operations leaders.

## Questions

1. Which assets need pricing action because occupancy, exposure, concessions, and comp position point in the same direction?
2. Which assets should be held for regional review because absorption risk is too high for a simple rent increase?
3. Which lease-up or turnaround assets are drifting against budget early enough to correct?
4. What rationale should accompany each recommendation so operations leaders can challenge or approve it quickly?

## Method

1. Generate a property portfolio with stage, housing type, market, submarket, unit count, and regional ownership.
2. Generate weekly leasing and financial signals: occupancy, traffic, tours, applications, signed leases, renewals, rent, concessions, exposure, actual NOI, and budget NOI.
3. Generate market comp signals: comp effective rent, subject rent position, comp occupancy, submarket traffic index, and new supply.
4. Score pricing pressure using comp position, target occupancy gap, traffic trend, concessions, and exposure.
5. Assign approval lanes based on confidence and absorption risk.
6. Rank forecast risk using occupancy gap, negative NOI variance, exposure, concessions, and traffic trend.

## Outputs

- A portfolio cockpit for market and stage-level review.
- A pricing approval simulator that mirrors a revenue-management system review.
- A forecast watchlist for assets needing regional action before a monthly review.
