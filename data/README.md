# Data Sources

Synthetic source-style data for multifamily revenue optimization.

- `entities.csv`: 36 property asset records.
- `daily_metrics.csv`: 5,040 property asset-day metric rows.
- `source_events.csv`: 760 operational events, QA checks, experiments, and stakeholder asks.
- `recommended_actions.csv`: 220 candidate actions with effort and expected lift.
